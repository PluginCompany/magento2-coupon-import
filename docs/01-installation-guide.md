# Installation Guide

Below you will find a step by step guide for the installation of the Magento 2 Coupon Import extension using the **command line**. You can install the extension with Composer (recommended) or by copying the files manually. The extension is free and open source, released under the MIT License. Its source code and releases are published on GitHub in the [magento2-coupon-import](https://github.com/PluginCompany/magento2-coupon-import) repository.

Please follow the installation guide carefully to prevent errors in your production environment.

> **Note:** Always install the extension on a staging server first in order to detect any issues which might arise and make a backup of your production environment before migrating.
